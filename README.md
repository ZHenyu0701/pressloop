# MITmodel

EDA/HR machine-learning experiments, inference scripts, and Raspberry Pi inference code.

## Project layout

- `contrastive-learning-for-eda/`: contrastive learning, preprocessing, training, and evaluation. See its README for setup and usage.
- `Raspberry pi/`: inference code and configuration for Raspberry Pi deployments.
- Root Python scripts: inference, training-history export, and visualization utilities.

The contrastive-learning subproject is based on https://github.com/kmatton/contrastive-learning-for-eda. Its original README is preserved.

## Local assets

Virtual environments, datasets, experiment logs, generated outputs, and trained model files are excluded from this repository. Obtain or generate the required datasets and models separately, and adjust local paths in configuration files before running the scripts.
